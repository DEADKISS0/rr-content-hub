## Criterio de salida para Supabase

No se retira Workspace Mode hasta que estas pruebas pasen con dos sesiones distintas:

- Un owner crea una idea y un colaborador asignado la ve.
- Un cliente solicita ajustes y el owner recibe el evento.
- Un editor sube V1, RR la ve y se conserva V0.
- Un usuario ajeno no puede leer ni adivinar la URL de otro proyecto.
- Un archivo privado solo se entrega mediante URL firmada autorizada.
