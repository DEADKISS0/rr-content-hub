## 1. Qué es este desarrollo

RR Content Hub es el sistema multi-cliente de RR ALIADOS para llevar una pieza
de contenido desde la ideación hasta la publicación: banco de ideas con briefs
(cámara, talento, edición), colas por fase (aprobaciones → producción →
publicación → métricas), hilo de comentarios compartido, historial de versiones
de archivos y trazabilidad de cambios. Tres proyectos viven dentro: Wundeer,
Satiro y BOGA. Stack: Next.js 16 (App Router) + Supabase (Postgres/Auth/
Storage) + Vercel. Las tablas usan el namespace `rr_hub_*` dentro del proyecto
Supabase compartido con el CRM.

Modo actual: público (sin login), con una rama colaborativa en Wundeer donde
cualquiera con el link puede comentar y editar.
