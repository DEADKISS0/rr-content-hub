# RR Content Hub — Design System

## Dirección
Brutalismo Urbano Cyberpunk Místico (B.U.C.M.) de RR ALIADOS: alto contraste, líneas duras, tipografía contundente y color usado para orientar decisiones.

## Tokens
- `#070001` negro estructural
- `#fffff3` blanco cálido para lectura
- `#be076d` fucsia para acción y foco
- `#ded116` mostaza para estados y atención
- `#973d8f` orquídea para contexto y pendientes

## Interacción
- Cada pantalla tiene una acción primaria visible.
- Cada idea tiene referencia visual integrada, brief por rol, hilo común y archivos/versiones.
- En móvil, navegación accesible, controles táctiles y ningún contenido depende de hover.
- No usar tarjetas anidadas ni adornos que compitan con la decisión creativa.
